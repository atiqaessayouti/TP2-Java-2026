 Collections & Streams

### 1. Lists

The objective of this activity is to create a simple Java application to manipulate
a list of product-type objects using Object-Oriented Programming principles.

---

## 🔹 Problem Description

1. Create a `Product` class containing the following attributes:
   - `id` (long)
   - `name` (String)
   - `price` (double)

2. Create a class called `ProductManagementApp` containing the `main` method.

3. Inside the `main` method:
   - Create an `ArrayList<Product>`
   - Add several products to the list
   - Delete a product from the list
   - Display the list of products before and after deletion

---

## 📄 Files Description

- `Product.java`  
  Defines the `Product` class with attributes, constructor, and `toString()` method.

- `ProductManagementApp.java`  
  Contains the `main` method and demonstrates list manipulation using `ArrayList`,
  Generics, and Stream operations.
